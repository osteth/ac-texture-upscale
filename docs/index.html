Why it's different

A graphics upgrade that doesn't cost you a server

Servers have tried custom dat files before. But once you install one server's files, you have to swap back to the end-of-retail files to play anywhere else. So nearly every server sticks to end of retail, and Asheron's Call has looked the same for over twenty years.

Works on every end-of-retail server

AC-HD only touches textures. Version numbers and all gameplay data stay exactly end of retail, so servers see a normal retail client.

Nothing for server admins to do

It's entirely on your PC. Servers need no changes, no patches and no permission, and nothing changes for other players.

Switch back in a second

Two buttons swap between AC-HD and the original textures instantly, and uninstalling puts your original files back. In Vitaeum, each launch row can use its own files.

Where AC-HD fits

The in-game option Environment Texture Detail decides how sharp textures are. AC-HD shifts every step of it up one notch, so the two overlap. Drag along the scale to see which one fits your setup.

Landscape Texture Detail (the ground) follows the same steps: AC-HD at Medium matches retail at High. Tip: the game's overall "Very High" preset only sets Environment Texture Detail to High, so pick Very High yourself to get the high-res textures.

Install

Pick your launcher

The download is a complete set of game files in one folder, HD DATs. Use it straight from that folder in Vitaeum, or copy it over your game files for ThwargLauncher.

Vitaeum

  1. Extract the zip somewhere permanent, for example Documents\AC-HD. Vitaeum reads the files from there.
  2. For every character: Settings › Retail DAT files › Choose folder, and pick HD DATs.
  3. Or just some characters: open a launch row in Favorites, click Choose next to DAT files, pick HD DATs, and save the row.

Want retail and HD side by side? Leave the default on a retail set and give your HD rows the HD DATs folder. Each login uses its own row's files, so both can be logged in at once.

ThwargLauncher (retail client)

  1. Close Asheron's Call and ThwargLauncher (check the system tray).
  2. Extract the zip anywhere, for example your Downloads folder.
  3. Copy the four files from HD DATs into your Asheron's Call folder (usually C:\Turbine\Asheron's Call) and choose Replace.

To go back, copy the four files from AC-Retail-DATs over them the same way.

Need the original files? AC-Retail-DATs is a clean set of all four end-of-retail dat files: a second set for Vitaeum, or a way back if your originals are missing.

Questions

FAQ

Can I still play on other servers?

Yes, on any server that runs the end-of-retail game files, which is nearly all of them. AC-HD keeps every version number and all gameplay data identical to end of retail. Servers that ship their own custom files still need their own files.

Does the server need to install anything?

No. Everything happens on your PC. Server admins don't need to do anything, and other players see no difference.

Does it change gameplay?

No. Only how textures look. Items, creatures, spells, maps and everything else the game logic uses are untouched.

Will it slow my game down?

Areas take a moment longer to load the first time you visit them, and the game uses more memory: about 1.6 GB in busy outdoor areas, compared with about 1.2 GB. That's well within what the client can use (4 GB). If your framerate drops, lower Environment and Landscape Texture Detail one step: AC-HD at Medium costs about the same as retail at High. See Where AC-HD fits.

How do I go back to the original look?

In Vitaeum, point the launch row back at your retail folder. With ThwargLauncher, download AC-Retail-DATs and copy its four files into your Asheron's Call folder, replacing the HD ones.

Is it safe? What does it change on my PC?

With Vitaeum it changes nothing in your game folder: Vitaeum reads the HD DATs folder where you extracted it. With ThwargLauncher, you copy the game files over your own, and only client_portal.dat and client_highres.dat actually differ from retail. There's nothing to run: no installer, no scripts, just data files. The download includes SHA-256 checksums, and the full source is on GitHub.

How was it made?

Each texture was upscaled with the Real-ESRGAN AI model, color-corrected against the original, and packed back into the game's own formats. The outdoor ground needed special handling to fit the client's terrain blending. The whole process is documented on GitHub.

I had a crash. What should I do?

Switch to retail textures and see whether it happens again. If it only happens with AC-HD, report where you were and what you were doing on the GitHub issues page. Rare crashes when portaling into very busy towns also happen on the original textures.
