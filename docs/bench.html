AC-HD Texture Bench

HD textures that stay end-of-retail compatible. Custom dat files lock players into one server; this pack changes only textures, so every end-of-retail server still sees a normal retail client. Install once, play anywhere, nothing for server admins to do.

Download HD Textures v1

819 MB zip. Close the game, extract, and run Install HD Textures.bat. Switch back to retail any time with Use Retail Textures.bat. Client-only, so it works on any end-of-retail server. Mirror: MEGA · source and docs
